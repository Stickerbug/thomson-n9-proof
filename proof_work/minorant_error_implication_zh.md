# 势函数近似误差与三点模型失败的区分

已通过certify_h11_competitive_error.py精确验证：保存的有理h满足
0<=f(t)−h(t)<3/10000，对所有−1<=t<=57/100成立。
下不等式引用先前完整minorant证书；上不等式由
(2−2t)(h(t)+3/10000)^2−1>0且h+3/10000>0证明，
二者的单变量Bernstein系数均严格为正，无需细分。

固定同一组核F,c及d(t)=F(1,t,t)。若用任何新的minorant h_new<=f替代h，
则每个竞争域三角的残差增量满足
R_new−R_h=sum(h_new−h)<=sum(f−h)<9/10000。
因此若某固定核在该域某点的R_h低于−9/10000，任何仅改善minorant的操作
都不可能修复这组核的全域非负性。新核或新的证书形式仍可能成功。

六阶条件域实验给出的约−0.8088违例是浮点诊断，尚未单点严格认证；
它的数量级远超0.0009，表明应优先改变核模型，而不是调整h近似精度。
八阶实验改用真实Coulomb势训练，便于进一步区分两类障碍。
