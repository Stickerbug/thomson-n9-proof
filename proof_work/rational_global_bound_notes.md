# 九点 Coulomb 能量的严格有理全局下界

结论：对单位球面上任意九个点，E >= 51458779692279/2000000000000 = 25.7293898461395。

## 构造和精确验证

取有理系数 p(t)=sum_{l=0}^{24} a_l P_l(t)，P_l(1)=1。
全部精确系数见 rational_lp24.json。发现阶段使用浮点LP，但验证不依赖求解器。
将 a_0 减去1/1000000以留出余量，其余系数量化到分母10^12。
验证所有 l>=1 的 a_l>=0。

随后计算有理多项式 R(t)=1−(2−2t)p(t)^2。
对 t∈[-1,1)，若 R(t)>=0，则 |p(t)|<=1/sqrt(2−2t)，故p<=f。
为验证 R>=0，把 t=2x−1 代入得 sum_j c_j x^j (次数49)。
其49次Bernstein系数为 b_k=sum_{j<=k} c_j*C(k,j)/C(49,j)。
若所有b_k>=0，则多项式在[0,1]非负。
用de Casteljau算法在中点细分直到各叶区间全部Bernstein系数非负。
此次只有12个叶子，最大深度6；每步只用Fraction精确有理数运算。

由球面加法定理，M_l=sum_{i,j}P_l(x_i dot x_j)>=0。
于是 E>=sum_{i<j}p(t_ij)
=(81a_0−9p(1))/2+(1/2)sum_{l>=1}a_l M_l
>=36a_0−(9/2)sum_{l>=1}a_l
=51458779692279/2000000000000。
