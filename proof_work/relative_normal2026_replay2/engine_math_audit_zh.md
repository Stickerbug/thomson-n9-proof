## 2. 下包围目标及 10 eps

设真正对称多项式 F 的系数区间中点为 M，系数半宽总和为 eps。物理域的各坐标绝对值不超过1，故 |F-M|<=eps。把 M 对六个坐标排列取平均仍满足该误差，因为 F 真正对称。对角 d(s)=F(1,s,s) 同样满足 |d-dM|<=eps；这里额外的坐标1仍满足绝对值不超过1。

因此真实三点残差

R_f(u,v,t)=f(u)+f(v)+f(t)-7F(u,v,t)-d(u)-d(v)-d(t)-c

下界为

sum_s [f(s)-dM(s)] -7M(u,v,t)-chi-10eps。

其中 chi>=c，10eps 恰好来自7eps+3eps；delta=0，没有人为下移目标。对称化、对角代入及误差估计均不要求端点区间多项式本身精确对称。

## 3. 每轴 Taylor 下界

当前一维区间为 [l,r]，s=(x-l)/(r-l) 属于[0,1]，lambda=(r-l)/(1-l) 属于(0,1)。令 a0=1/sqrt(2-2l)，则

f(x)=a0*(1-lambda*s)^(-1/2)。

二项式级数系数 comb(2k,k)/4^k 全部非负，所以保留0..10项是下界。代码 n=isqrt(floor((2-2l)^(-1)*scale²)) 精确等于 floor(scale*a0)；每项再整数下取，因此 af[k]/scale 分别不超过真实 Taylor 系数。这里使用正系数和 s>=0，没有交错余项假设。

## 4. d 的上包围、高阶尾项与10次 Bernstein

dM 的20次 Bernstein 系数先向上量化，再在细分过程中逐步向上取平均。因此当前 D_hi(s) 在整个[0,1]上不小于 dM(x)。从这组上系数转换到幂基的 ad[k] 是纯整数精确前向差分，不再把幂系数分别误当上界。

对 s 属于[0,1]，高阶和 sum_{k=11..20} ad[k]*s^k <= tail=sum max(ad[k],0)。于是

sum_{k=0..10} (af[k]-ad[k])*s^k - tail <= scale*(f(x)-dM(x))。

这正是代码构造的 q。其10次 Bernstein 系数为 sum_{k<=i} q[k]*comb(i,k)/comb(10,k)。2520 是所有 comb(10,k) 的公倍数；整数除法 //2520 向下取整，对负数亦然。因此获得逐系数下包围。无需假设转换所得 ad[k] 的符号。

## 5. 三轴合成、边界乘子与 signed128

三元 K=-7M-chi-10eps 采用每轴10次、11×11×11系数的 Bernstein 变换并向下取整。每轴 H 也以10次 Bernstein 表示，故三元残差下包围系数恰好是 K[i,j,k]+H_u[i]+H_v[j]+H_t[k]；最小系数非负足以证明整个盒非负。

边界变体只额外减去 lambda*Gram。所有 lambda 都是非负有理数；在 Gram>=0 的物理域，R_f >= lower >= lower-lambda*Gram。故该差的非负性足够，不要求 lambda 精确等于某个法向导数。激活半径仅控制是否保留一种充分测试，没有删除物理点。

C 辅助程序逐项检查输入绝对值<2^124。四项相加的绝对值<2^126，所有中间和均在 signed128 的[-2^127,2^127-1]内；初始最小值2^126大于所有可能结果。加载和写回使用 memcpy。细分的两数加舍入标志绝对值<2^125+1，也不会溢出；对负奇数补减1实现数学 floor，对 upper=1 得到 ceil。shape/字节序/补码布局与指针封装由原 backend 护栏保证。超范围直接报错；新 H 的粗盒范围不足时仅跳过一个充分测试，仍保留该盒并继续细分或通过其它终止条件，不会把该盒当成已证。

## 6. 覆盖与局部盒

根盒 [-1,14/25]^3 包含 pair056 缩减后的全部三点内积。真正残差在三坐标排列下不变，所以只需覆盖 u<=v<=t。仅在某个较早坐标的下端严格大于较后坐标的上端时剪去全盒；边界相交保留。Gram 的 Bernstein 系数始终向上包围，max<0 才排除，故不丢掉 Gram>=0 点。

局部盒由本轮真正重证的物理盒取得：取各轴区间中点，再取三个半边长的最小值，逐轴精确检查新立方体内接原证明盒。中心是定点有理数，故 engine 的 core 与该内接立方体完全相同。必要的坐标排列由真实对称性转移，不能由旧模型盒转移。

局部 R_H>=0 推出 R_f>=0，因为 true Hermite H27<=f：28阶导数正，余项为14个平方因子的积乘正因子。边界局部证明要求在扩展 u 区间上 R_u>0，并在 lower Gram graph 上证明有理 congruence 后 Hessian 正定；扩展 u 区间只是证明辅助，不被当成全域终止区域。精确零值/切向梯度来自45接触兼容性定理。

每次二分产生两个闭子盒覆盖父盒；没有非终止盒被遗弃。visited=terminals+splits、terminals+pending=splits+1，加上 pending=0 和完整根域启动，构成完整二叉覆盖检查。深度、时间、栈或数值护栏不足均不能给 CLOSED。
