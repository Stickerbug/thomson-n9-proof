# T1球面参数导数：面向1e−6邻域的可执行严格方案

本文件是数学与实现设计，不是新的参数立方体认证。没有重新运行球面图、导数全域根验证或长solver。父线程继续处理T2低pair。

## 1. 必须先合并参数导数，再做球面界

令T=(u,v,t)，a=(1,0,0)，s=√(1−u²)，w=(t−uv)/s，z=√(1−v²−w²)，b=(u,s,0)，c=(v,w,z)。此z等于√detGram/s。设q为固定单位向量，A=a·q，B=b·q，C=c·q。

phi=R(u,A,B)+R(v,A,C)+R(t,B,C)。记R_j为第j个输入的偏导，输入下标0,1,2。对参数k∈{u,v,t}，有精确恒等式

D_k phi = 1[k=u] R_0(u,A,B) + R_2(u,A,B) B_k
           + 1[k=v] R_0(v,A,C) + R_2(v,A,C) C_k
           + 1[k=t] R_0(t,B,C) + R_1(t,B,C) B_k + R_2(t,B,C) C_k。

这里A_k=0，B_k=b_k·q，C_k=c_k·q。必须先将右侧所有项加成单一球面多项式，再求绝对界；先各项绝对值上界求和会重新引入v3薄层的巨大保守损失。

锚点导数明确为：s_u=−u/s，s_v=s_t=0；b_u=(1,−u/s,0)，b_v=b_t=0。

w_u=−v/s+(t−uv)u/s³，w_v=−u/s，w_t=1/s。

z_k=−(v*1[k=v]+w*w_k)/z，c_k=(1[k=v],w_k,z_k)。

所有这些量可直接用已有I384实现，以固定参数有理输入或参数区间输入计算。只要s,z远离0，该计算不需要新的根求解。

## 2. 二维齐次多项式与精确界

在两个半球图q=N/D，N=(2x,2y,sign*(1−x²−y²))，D=1+x²+y²。A,B,C及B_k,C_k都为二次多项式除D。旧R总次数≤27；上述合并导数的q次数仍≤27，故D^27*D_k phi是至多54×54次的二元多项式，对应55×55张量，与已有phi图认证同阶。

实现先生成R_j的精确有理系数字典，按固定边e收缩第一输入，再将每个R_j乘对应线性q形式并齐次化；全部贡献合并后再转换Bernstein系数。若锚点和导数用区间代数系数，可把每个最终monomial系数包围为[Lij,Uij]。现有coefficients只接受Fraction，因此先取区间中点构造精确多项式Pmid，再给出E=Σmax(|Lij−midij|,|Uij−midij|)；在|x|,|y|≤1上|P−Pmid|≤E。也可以实现对区间系数的精确有向线性Bernstein变换，通常比全域单一E紧。

给定候选M_k，分别认证 M_k*D^27−P_k>=0 和 M_k*D^27+P_k>=0。半球圆盘、锚点约束只在整盒严格失败时剪枝，其余完整根域细分，零pending才允许声称|D_k phi|≤M_k。可共享两个符号、三轴的细分树，难盒才细分；下界取整必须朝下。

单纯根Bernstein系数可能受图上域外部分影响，不能把rootbound差当作实际导数大。半球圆盘及允许锚点cuts对小叶很有价值。不能用旧894个T2盒或离散低井替代T1完整导数球面覆盖。

固定T0的三轴六张二维转换，与已完成T1原phi认证同级，合理首轮预算60秒，但不能保证精确耗时。普通浮点中心和有限采样仅用于选M，最终必须I384误差加精确Bernstein覆盖。

## 3. delta=1e−6必须重跑更宽固定允许域

若新三角T满足锚点内积≤.56且|T−T0|∞≤δ，则固定锚点点积≤.56+8δ。δ=1e−6时至少需要固定T0的chart允许上界 .560008，旧 .56000001证书不能复用。需要新独立宽域证书认证同球帽的m/M或调整后的阈值；若固定宽域下已有低phi点破坏旧阈值，后续导数再紧也不能沿用旧sixlower。

对中间参数T'，若q在新端点T允许域，则q与中间锚点内积仍≤.56+8δ（以T为基准，T'沿T0至T距离≤δ）。因此若直接认证参数区间上的D_k phi，可以使用宽域fixed cuts加误差调整；不能仅保留在中心允许域内的q。简单安全做法：对固定锚点先筛q·anchor(T0)≤.56+8δ，全部导数域覆盖此集合。为避免区间cuts误删，若导数是在T'变化锚点上筛，阈值需再保守到.56+16δ，或完全不施加变化锚点cut。固定中心cuts最清晰。

## 4. 中心一阶界加粗二阶项：量化瓶颈

从原有理R独立重算，S1=Σ|c|d≈177032.5228311875，S2=Σ|c|d(d−1)≈2399169.3487984017。完整精确值可由旧model瞬时重算。系数和没有利用球面消除，所以即使中心导数M很小，粗二阶界仍可能挡住1e−6。

若参数方向h满足||h||∞≤1，在整个目标邻域认证每个R输入路径||x'||∞≤8、||x''||∞≤A2，则每个R的二阶方向导数≤64*S2+A2*S1。三项phi合计H≤3*(64*S2+A2*S1)。即使不计A2，H已约4.6064e8。六点二阶余项≤3*H*δ²，在δ=1e−6时约.00138，远大于原裕量约.0000188。所以仅凭中心导数变小，再接原系数和二阶界，不能合理声称可到1e−6。这是明确量化的瓶颈，不是计算未完成。

要达到1e−6，必须也收紧二阶余项，或直接对整个参数box认证一阶导数。预算R(T)应在很小三参数box独立认证其三轴导数和G；不应继续把全输入cube的1669当预算梯度。它是低成本三维局部Bernstein操作，避免让预算本身消耗.001669的裕量。

## 5. 推荐直接用参数区间系数，避免显式粗二阶项

取目标参数boxT0±1e−6，直接用I384传播s,w,z及其一阶导数，生成每个P_k(T;x,y)的区间系数。接着对两个球面图作上述严格二维Bernstein认证，得到对所有T'∈box同时成立的|D_k phi_T'(q)|≤M_k。参数变量没有增加张量维度；代价是区间系数宽度可能因取消过大。若失败，可将参数box按八子box拆开并合并M_k，或用中心+一阶区间系数Taylor改善依赖，不必先构造完整五维张量。

同时在同box精确认证预算梯度和G。若宽域固定球帽认证得到sixlower0，则最终充分条件为

sixlower0−K0−(6*(M_u+M_v+M_t)+G)*δ > 0。

delta=1e−6时，若sixlower0仍为.00046，则必须6ΣM+G<18.80634961063067。比如ΣM≤2、G≤1时尚有余量；ΣM≥3.135且G非负时即使没有二阶项也不足。这个阈值可用于快速判定导数路线是否值得完整认证，而不能预先假定M足够小。

若只认证中心导数并另有严格参数H界和预算二阶界Hb，则应使用含(3H+Hb/2)*δ²的充分条件；不能漏掉该项。实际更建议区间参数一阶界，因为它直接对积分路径有效。

## 6. 交付边界与执行顺序

先数值或I384单点AD生成三轴合并多项式，查符号/导数和有限样本量级；再在宽域q上认证固定中心导数，必要时中止；只有ΣM可低于上述阈值，才做整个参数box的区间系数界与宽域fixedchart。最终保存所有系数误差、rootbox、cuts、分支叶、预算梯度和依赖哈希。

本次仅完成推导及S1/S2的真实精确系数和计算，没有启动球面导数根认证。能否到1e−6目前未定；仅凭粗二阶L1界可以明确判断该直接方案不够，而完整参数区间导数方案有有限二维实现路线，必须实际认证后才能给出结论。
