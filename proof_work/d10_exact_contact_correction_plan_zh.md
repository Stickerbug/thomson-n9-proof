# 十阶数值核转为真实驻点精确接触核：有限可执行方案

本轮只读父模型，未改写父数值模型、既有证书或脚本。目标是修正真实 r* 的接触等式，不把任意有理近似 r0 当成驻点。

## 已完成的小型严格检查

`d10_contact_left_geometry_v1.py/json` 构造45行接触/切向算子的12个几何左关系向量W。
10行来自F及L的坐标排列对称性；第11行为12种三角按multiplicity加权的值之和；第12行为沿候选半径变化速度加权的方向导数之和。

选出的12x12子式精确行列式是 −36r，并已在已认证r*区间内严格排除零。因此rank(W)=12是严格结论。
把6个Coulomb接触值降为5个formal generators时，必须先使用

    f_D=r f_A，A=1−3r²/2，D=−1/2，r>0。

余下顺序为(A,B,C,F,G)。所有接触及切向右端写为H(r)乘此5向量。程序精确验证

    W(r) H(r) = [0; ...; 0; 7 e(r)]，
    e(r)=(-6/r, 3r/(1−r²), 6r/(4−r²), 6/(2−r), −6/(2+2r))。

故唯一剩余右端条件正是E'(r)=e(r)·f=0。以上是Q(r)精确恒等，不是浮点rank。

`d10_contact_modular_structure_v1.py/json` 另直接重建十阶190变量算子，在(prime1009,r7/10)、(prime1013,r5/7)两次有限域专门化中得到rank(M)=33，且消元后的5fi右端障碍恰1维并全为E'倍数。两次共同pivot columns为

    0,...,26,45,46,54,55,56,57。

这两次有限域检查是选主元的结构证据，不是rank(M(r*))=33或Q(r)完整恒等的证明。脚本耗时3.86秒，exit0；几何W脚本exit0。自启任务均已收集。

## 为什么W应对全部190列成立

前10行由L的完全对称性直接成立。令候选点积核和为Gk(r)，Nk(r)为由features两行精确构造的共同零空间，取任意固定对称Bk，并令Ak(r)=Nk(r) Bk Nk(r)^T。

需要独立验证全部k≤10的精确恒等

    Gk=6(1−r²)^(k mod2) pk pk^T+3 ck ck^T，Gk Nk=0。

有此恒等后，任意这类F的12种三角加权L之和满足

    S(r)=Σmultiplicity L = (7/6) Σk <Ak(r),Gk(r)> =0。

这给第11个左关系。对r求导时，Ak'(r)=Nk' Bk Nk^T+Nk Bk Nk'^T，故

    <Ak'(r),Gk(r)>=0。

所以S的总导数中由系数变化产生的项为0，剩下的就是保持F系数固定、只改变候选三角坐标的方向导数，即第12个左关系。这是W M_all=0的几何证明，覆盖全部190列及任意自由seed，而不只覆盖挑选的33列。

注意：本轮未新执行k≤10全部Gk的Q(r)重建检查。现有d4经验不能替代这一步。实现上可独立用九点精确dot表、锚点轨道权重6和3及Qk递推重建G；无需展开完整uvt多项式，也无需33阶符号逆。

## 最小剩余严格任务

1. 以Q(r)构造Nk并独立验证上述全部Gk恒等及GN=0；检查每个秩主元在r*区间非零。
2. 用12几何关系验证/证明W M_all=0。rankW=12已严格认证，因此rankM≤33。
3. 数值仅用QR选择33行与33列。以384bit或更高位整数区间在整个已认证r*区间证明该33x33子矩阵LU各主元不含0，得到rankM≥33。
4. 合并得到ImM=kerW，且真实r*满足W H f=0。因此接触/切向系统在真实r*精确可解。

上述步骤不需要任何巨大Q(r)矩阵逆。仍未完成步骤1、3，故本轮不宣称已证明十阶精确接触可解，更未证明PSD或全局R非负。

## 从父模型做小校正并保存精确构造

父模型的N来自数值QR。不要直接把浮点N视作精确零空间。先在真r的Nk(r)后乘一个常数有理可逆矩阵Tk，使Nhat_k(r)=Nk(r)Tk在r*附近接近父QR基。Tk由数值最小二乘发现后有理化，并认证其可逆性。此改变不影响共同零空间，但改善区间条件数及PSD校正的可解释性。

将父reduced B变换至Nhat坐标并有理化为seed x0。固定所选33列以外的157个seed分量。设C为33列，J为33行，则精确定义

    x_C(r*) = M_JC(r*)^(-1) [H_J(r*) f(r*) − M_J,rest(r*) x0_rest]，
    x_rest=x0_rest。

不必把逆展开成巨型有理函数；保存Nk、Tk、seed、行列索引及此线性定义便能精确确定证书。利用W M_all=0、rankW12和rankM33，所选33行方程成立即可推出全部45行成立。

这个all-column argument不能省略：只验证33 selected columns加fi RHS，不能保证任意非零157变量seed的余量仍兼容。

区间求解可直接计算Δx_C=M_JC^(-1)(H_J f−M_J x0)，并保存包络。若残差与逆范数允许，则认证ΔB很小。父数值最小特征值约2.344e−6，只是发现值；需要先认证有理seed减去适当εI严格正定，再用max行绝对和或Frobenius界控制ΔB的谱范数。最终可以对修正后的代数区间矩阵直接做区间LDL。不能仅凭“校正看似小于1e−6”声称PSD。

## 与全局证明的界限

接触等式与PSD即使都严格化，仍只完成候选等号及核正性。R在竞争条件C≥0及Gram域的非负性、接触邻域的局部非负证明、其余区域的Bernstein/SOS/区间排除仍须另做。父全域搜索的最坏负点若已被C排除，不构成完整剩余域认证。

本轮没有改动父model，也没有启动巨大符号逆或新的SDP搜索。
