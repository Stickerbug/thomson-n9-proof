# n=10 全局下界进展（2026-10-25）

本轮加入了一个独立的、有理数 Bernstein 证书。它把十粒子问题的全局能量下界从通用粗界推进到

\[
 E_{10}\ge \frac{326807}{10000}=32.6807.
\]

D4d 对称族候选的数值能量约为 `32.71694946014759`，所以当前仍有约 `0.03624946015` 的缺口。这不是 n=10 最优性证明。

## 证书内容

令

\[
f(t)=(2-2t)^{-1/2},\qquad p(t)=\sum_{k=0}^{12}a_kP_k(t),
\]

其中 `P_k` 是 Legendre 多项式，非零系数为

```text
(a0,...,a12) =
(41269/50000, 25267/50000, 3233/12500, 10131/100000,
 47/2000, 0, 0, 109/50000, 131/100000, 0, 0, 0, 0).
```

脚本先在整数有理算术中构造

\[
R(t)=1-(2-2t)p(t)^2.
\]

把 `t=2x-1` 后，`R` 是一个 25 次多项式。精确 de Casteljau 中点细分得到 9 个 Bernstein 叶区间，最大深度为 6，所有叶子的 Bernstein 系数均非负。因此 `R(t)≥0` 在 `[-1,1]` 上成立，从而 `p(t)≤f(t)`。

对任意十个单位球面点，球面加法定理给出

\[
\sum_{i,j}P_k(x_i\!\cdot x_j)\ge0.
\]

因此

\[
E=\sum_{i<j}f(t_{ij})\ge\sum_{i<j}p(t_{ij})
=\frac{10^2a_0-10p(1)}2
=\frac{326807}{10000}.
\]

## 可信边界

这是外部精确算术证书，不是 Lean 重放。当前 Lean 还没有把这组 13 个系数、Legendre 加法定理和十粒子能量组合成正式 n=10 下界定理。即便补上这层，`32.6807` 仍低于 D4d 候选，无法关闭全局缺口。下一步应把该证书先接入通用 `LowerBoundBridge`，再针对约 `0.03625` 的缺口加入三点/Gram 相关性或局部覆盖证书。
