# 当前四阶三点 sharp 证书的不可能性

本文件配套 `actual_d4_contact_cert.py`。结论只针对下述 d=4 截断的对称三点核，不排除其他三点强化、不同截断、区域化证书，也不是 Thomson 九点候选的反例。

## 定理及适用范围

设 f(t)=(2−2t)^(-1/2)，r* 位于
[0.71054833409295381132770417927279124376803,
 0.71054833409295381132770417927279124376804]。
令九点候选是半径 r*、高度 ±sqrt(1−r*²) 的对齐正三棱柱六顶点，及赤道上相差 π/3 的三个帽点。
在以下标准四阶截断中，不存在达到该候选能量 E* 的 sharp 下界证书：

- Q0=1，Q1=t−uv，Q(k+1)=2(t−uv)Qk−(1−u²)(1−v²)Q(k−1)；
- Yk(i,j)=u^i v^j Qk，0≤k≤4、0≤i,j≤4−k；
- F 是 Σk〈Ak,Yk〉 对 u,v,t 的六排列平均，Ak 为半正定矩阵；
- h 是任意可微函数，在相关点积域满足 h≤f；
- d(t)=F(1,t,t)，R=Σh−7F−Σd−c，在相关三角 Gram 域非负；
- 给出的能量下界 B=12c−(3/2)F(1,1,1)。

结论既适用于完整 Gram 域，也适用于所有坐标≤0.57 的条件 Gram 域，因为六个候选点积严格位于 (−1,0.57)，九个使用梯度的候选三角都是该条件域的内部点。

## 从 sharp 到必要线性系统

对任意九点，有缺陷恒等式

E−B = Σ无序点对(f−h) + (1/7)Σ无序异点三角R
      + (1/6)Σ全部有序三指标F。

三个总项均非负。若 B=E*，在候选上三项均为零。因此：

1. h 在六个不同候选点积接触 f；由可微性及局部 minorant 条件，h'=f'。
2. 每个候选异点三角的 R=0；内部三角的三方向解析导数均为零。
3. 每块 〈Ak,Gk〉=0。精确候选核和为
   Gk=6(1−r²)^(k mod 2) pk pkᵀ+3 ck ckᵀ。
   奇数块 ck=0。Ak 半正定遂迫使其支撑于 pk、ck 的共同零空间。

程序直接从九点精确点积表重建全部有序核和，逐块验证上述 Gk 恒等式，不把浮点特征分解当作证明。共同零空间 Nk 使用多项式余子式构造；五个零空间维数是 3、3、1、1、0，全部必要秩主元在认证 r 区间上严格避开零。

写 Ak=Nk Bk Nkᵀ。先保留 Bk 的全部对称参数，不使用 Bk 半正定性：共有6+6+1+1=14个变量。若连这个放松的线性系统都无解，则原证书更不可能存在。

将 B=E* 代入得到 c=E*/12+F111/8。
令 L(F)=7F+d(u)+d(v)+d(t)+F111/8。
12种候选三角给出 L(F)=Σf−E*/12；9种内部候选三角的每个坐标给出
∂L(F)/∂coordinate=f'(coordinate)，共39个方程。
所有导数通过多项式指数的解析规则计算，没有有限差分。

## 精确消去 gauge

程序在 Q(r) 中构造14个 F 基多项式，并在精确系数矩阵上验证一条恒等关系，删除编号8的列。它是整个 F 多项式的恒等关系，不只是在接触点成立的关系。剩下的13列因此张成全部可能 F。

关系系数在 JSON 的 omitted_equals 字段中逐项保存。每个系数另用384位 dyadic区间评价，验证其分母在 r* 区间内非零；因而不能出现形式恒等关系在实际 r* 处无定义的漏洞。

用于寻找关系的有理点 r=71/100 只挑选候选主元。最终关系在 Q(r) 上逐个多项式系数重新核对。数值 QR 只选择39个方程中的13个候选行；它不参与任何真值判定。

## 区间消元的严格矛盾

所有 Q(r) 矩阵元素以精确有理系数 Horner 计算，所有 Coulomb 平方根与除法采用384位向外取整的整数 dyadic区间。
对挑出的13行做高斯消元，每个实际区间主元均严格避开零。由此任意真实共同解必须处于回代计算得到的13个系数包络内。
将这些系数包络代回未使用的第0个接触方程，得到严格残差

    −0.014300741173147
       < residual <
    −0.014300741173128。

JSON 同时保存两端的精确整数分子，公分母2^384；以上较宽十进制界也已用 Fraction 精确比较检查。精确上端严格小于零，因此39个必要方程无共同解，完成不可能性证明。

这里不存在 trace cap，也没有使用任何 SDP 求解器的不可行报告。证明不依赖11次 Hermite minorant，也不限制 h 的次数；只要求 h 在六个接触点可微。

## 参数和重跑

E(r)=sqrt(3)+2sqrt(3)/r+3/(2sqrt(1−r²))+6/sqrt(4−r²)
     +12/sqrt(2−r)+6/sqrt(2+2r)。
现有区间程序验证 E' 在区间左端负、右端正。在0<r<1，

E''=4sqrt(3)/r³ +(3/2)(1+2r²)/(1−r²)^(5/2)
    +6(4+2r²)/(4−r²)^(5/2)+9/(2−r)^(5/2)+18/(2+2r)^(5/2)>0，

故区间内根唯一。实际上上述线性排除在整个给定 r 区间上成立，不依赖根的任何额外代数关系。
