# Independent kernel complement and contact construction

This package constructs a new N(r) and independently evaluates the selected 33-contact system. It imports only this publication-validation directory's independent 640-bit interval arithmetic and small decode function; it imports no previous engine, I384 implementation or mathematical helper. Archived source definitions were read as mathematical specifications.

independent_contact_construction.py implements its own dense univariate polynomial arithmetic over exact Fraction coefficients. From the candidate anchor definitions it builds p_hat and c in Q[r]. At the exact rational midpoint it selects the first lexicographic nonzero two-column minor for rank-two blocks, or the first nonzero p coordinate for rank-one blocks. Every earlier midpoint-zero minor/coordinate is required to vanish identically as a polynomial, preventing floating or interval selection of spurious pivots. Odd cap rows are polynomially zero. For k=10 the ambient space is one-dimensional and its nonzero feature proves zero kernel dimension.

For rank two, det=p_a*c_b-p_b*c_a and each free j has numerator coordinates

num_a=p_b*c_j-c_b*p_j,
num_b=c_a*p_j-p_a*c_j,
num_j=det,

with every other coordinate zero. The actual vector is num/det. For rank one the corresponding numerator is num_a=-p_j, num_j=p_a. All chosen denominators are evaluated at the full root bracket with outward 640-bit arithmetic and certified strictly nonzero. The program proves p dot num=c dot num=0 by exact polynomial equality for every basis column, both before and after the archived rational basis transform T. Exact Fraction elimination proves det(T)!=0; the empty transform has determinant 1. The free-coordinate submatrix before T is an identity matrix, so these are full bases for the stated kernels, not just some null vectors. All transformed numerator polynomials, denominators, input polynomials, free and pivot columns, transformations and N interval columns are saved. The 190-coordinate order is required to exactly equal the certificate's index order.

independent_contact_solve.py uses four-component forward automatic differentiation: each scalar has a value interval and three first-derivative intervals, with addition and product governed by the ordinary sum and product rules. It does not reproduce the old DQ recurrence. The scalar Q_k recurrence is differentiated automatically. For each of the six permutations of (u,v,t), it evaluates

Q_0=1, Q_1=t-u*v,
Q_(k+1)=2*(t-u*v)*Q_k-(1-u*u)*(1-v*v)*Q_(k-1),

and multiplies Q_k by the two N-polynomial evaluations. Offdiagonal B coordinates contribute the sum of both orders. Averaging over permutations produces a symmetric scalar polynomial and its three partial derivatives. N coefficients depend on r and are constants with respect to u,v,t for this differentiation.

The contact polynomial column is P=7*f(u,v,t)+f(1,u,u)+f(1,v,v)+f(1,t,t)+f(1,1,1)/8. Its gradient follows by the chain rule on each repeated diagonal argument. Boundary tangent rows use g_0*partial_i(P)-g_i*partial_0(P), where g is the gradient of the Gram determinant. Scalar pair-energy values and slopes are evaluated with the independent strict sqrt enclosures. The equation selection and row metadata are explicit inputs from the source certificate and are saved. This sublayer does not independently rederive which triangle types must occur in the candidate configuration.

For the selected 33 equations and 33 coordinates, the other 157 coordinates remain the exact rational seed. The independently evaluated residual is rhs-M*seed. Interval Gaussian elimination chooses only pivots whose intervals strictly exclude zero, saves every pivot and row swap, and encloses the unique exact selected solution for every r in the root bracket. Back substitution yields delta, and seed+delta gives all 190 new coefficient intervals. Exact rational comparisons test each new interval is contained in its corresponding original reduced_solution_enclosure. The result distinguishes successful solve with failed inclusion from a complete inclusion pass.

The kernel result's status CONTACT_SOLVE_PENDING describes the saved kernel-only artifact. The separate contact-solve result is authoritative for the subsequent solve and inclusion status. They are separately named immutable stages, rather than changing the earlier artifact when the next stage finishes.

Multiplication takes all four endpoint products and rounds minimum/maximum outward; reciprocal uses floor(S*S/h) and ceil(S*S/l); square roots use isqrt(l*S), ceil_sqrt(h*S), with exact endpoint-square rechecks. The original Fraction-backed Box is the comparison oracle, not the archived I384 implementation. Two saved differential-test artifacts cover 5,984 exact endpoint comparisons, including signed wide intervals, zero boundaries, negative reciprocals, powers, square roots, and subulp inputs; all agree. Three invalid interval cases are rejected. Independent AD/Gauss/kernel component checks include three further mathematical rejection cases. The hand-expanded Q2 and all 44 value/partial evaluations of Q0 through Q10 also pass exact-rational crosschecks.
