# Thomson 九点证明候选：发表级验证进展

本目录验证的是尚未经过外部评审的证明候选。目前已经有完整覆盖树和独立算术子层；候选几何、族能量恒等式、一阶与二阶导数、驻点存在唯一性、族内严格全局极小性，以及能量泛函的等距不变性、内积表示与粗下界等构件已由 Lean 检查，但九点最终定理尚未由 Lean 接受。不能把其中任一个子层的 PASS 改称为最终定理通过。

## 冻结命题与定义

目标是在单位二维球面上，对所有互异的九点构型证明库仑能量不小于三帽三棱柱候选的能量，同时验证该候选的球面约束、能量公式及族内唯一驻点。目标不包含所有全局极小构型的唯一性。数学规格见 [冻结命题](frozen_statement.md)，Lean 规格见 [Statement.lean](formal/ThomsonNine/Statement.lean)。后者仅定义命题，没有以假设或占位证明断言它成立。

## 覆盖结论的准确范围

根盒是 `[-1,14/25]^3`，树几何分区覆盖整个根盒。残差非负性的结论针对其中的物理有序域

`D = { (u,v,t) : -1 ≤ u ≤ v ≤ t ≤ 14/25, 1+2uvt-u²-v²-t² ≥ 0 }`。

`ordered_disjoint` 和 `gram_negative` 叶排除的是可行域；它们不证明整个相应盒上残差非负。实例化通用覆盖引理时，`inside box x` 必须包含 `x ∈ D`，或把 `goal x` 写成 `x ∈ D → R(x) ≥ 0`。边界乘子使用 λ≥0：若 `R−λ Gram ≥ 0` 且 `Gram≥0`，才得到 `R≥0`。
